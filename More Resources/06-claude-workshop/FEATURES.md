## Claude Code Workshop - Features

# Segment 01

1. **CLAUDE.md** - Project context files & architectural patterns
2. **Full-Stack App** - Build a Doctor-Patient system (Next.js, Prisma, SQLite)
3. **Skills** - Reusable skill folders with templates & validation
4. **Custom Agents** - Specialized `.agent.md` files (code review, docs, tests, security)
5. **Agent Tuneup** - Effort levels, background execution, isolation, agent-level hooks
6. **Hooks** - Auto-formatting, command blocking via PreToolUse/PostToolUse
7. **Claude Settings** - Environment variables & global configuration
8. **MCP Server** - Using mcp server with Claude Code for agent orchestration and communication
9. **Combining Features** - One command orchestrating all of the above end-to-end
10. **Claude Commands** - Custom commands for interacting with the application and its features (remote, loop, build in skills etc.)

# Segment 02
11. **Spec Driven Development with Claude Code** - Development guided by detailed specifications
12. **Frontend Design with Claude Code** - Frontend Designing with Claude Code
13. **Claude Code Test Automation** - Testing automation with Claude Code
