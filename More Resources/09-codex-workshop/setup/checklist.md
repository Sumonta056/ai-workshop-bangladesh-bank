# Workshop Checklist

## Before the Workshop

- [ ] Codex app or CLI access is available
- [ ] Git is installed and configured
- [ ] A GitHub account is available
- [ ] Node.js 20+ is installed
- [ ] A terminal and code editor are available
- [ ] The workshop repository is cloned locally
- [ ] You can run `git status`
- [ ] You can install dependencies for the sample project

## During the Workshop

- [ ] Create or review `AGENTS.md`
- [ ] Ask Codex for a project overview
- [ ] Ask Codex for a plan before edits
- [ ] Approve a scoped implementation
- [ ] Run verification commands
- [ ] Review the diff before committing
- [ ] Ask Codex for a code review

## After the Workshop

- [ ] Customize `AGENTS.md` for your own project
- [ ] Save reusable prompts
- [ ] Document your preferred test and build commands
- [ ] Practice one full branch-to-PR workflow
