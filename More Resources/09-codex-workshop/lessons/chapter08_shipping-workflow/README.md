# Chapter 8: Shipping Workflow

## Goal

Practice the final review loop before committing or opening a pull request.

## Exercise

Ask Codex:

```text
Summarize the current diff, list verification performed, and tell me whether this is ready to commit.
```

Only after reviewing the answer, explicitly ask Codex to commit if desired.

## Outcome

Participants understand how to keep commits intentional and reviewable.
