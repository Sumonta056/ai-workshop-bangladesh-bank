# Chapter 4: Code Review

## Goal

Use Codex as a reviewer focused on bugs, regressions, and missing tests.

## Exercise

Make or provide a small diff, then ask:

```text
Review the current diff. Prioritize bugs, behavior changes, security issues, and missing tests. Give file and line references.
```

## Outcome

Participants learn how to use Codex for high-signal review rather than style-only feedback.
