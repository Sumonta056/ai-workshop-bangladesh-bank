# Frontend .cursorrules Reference

Use this as a reference when completing the Hour 2 `.cursorrules` exercise in `frontend/`.

The active project rules live in `.cursor/rules/frontend-general.mdc` (Cursor Rules format with globs).

## Tech Stack

- Next.js 14 App Router
- TypeScript 5
- Tailwind CSS 3

## Component Standards

- Use 'use client' for client components
- Server components by default
- Functional components only
- Named exports (no default exports)
- Tailwind for all styling
