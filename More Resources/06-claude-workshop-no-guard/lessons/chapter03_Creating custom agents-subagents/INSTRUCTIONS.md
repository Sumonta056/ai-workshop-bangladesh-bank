## Corordinator's Instructions

1. Explain why custom agents are necessary and how they differ from a single generalist agent.
2. Describe the key benefits of having specialized agents for different roles and responsibilities.
3. Discuss how custom agents help in managing context and improving response quality.
4. Explain how custom agents can enhance collaboration and efficiency within a development team, especially when working on complex projects with multiple areas of expertise required.

## Leaning Outcomes

1. Learners will understand the importance of creating custom agents for specific roles and responsibilities in a development workflow.
2. Will be able to create custom agents with specialized expertise when necessary.
