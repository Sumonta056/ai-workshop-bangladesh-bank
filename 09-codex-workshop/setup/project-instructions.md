# Project Instructions with AGENTS.md

`AGENTS.md` is the project instruction file Codex reads to understand how to work inside a repository.

## What to Include

- Project role and expectations
- Build, test, lint, and development commands
- Architecture overview
- File ownership or module boundaries
- Coding conventions
- Safety rules for commits, pushes, deletes, and dependency installs
- Review and verification expectations

## What to Avoid

- Long generic advice that does not apply to the project
- Conflicting rules
- Commands that are not valid in the repository
- Instructions to make broad refactors during small tasks
- Secrets or private credentials

## Starter Template

Use [resources/templates/AGENTS.basic.md](../resources/templates/AGENTS.basic.md) as the first draft, then replace placeholders with project-specific details.

## Maintenance

Update `AGENTS.md` when:

- Build or test commands change
- The architecture changes
- New conventions are agreed
- Common mistakes need to be prevented
