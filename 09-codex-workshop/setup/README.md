# Setup Guide

This folder contains the setup material for the Codex Workshop.

## Files

- [checklist.md](checklist.md) - pre-workshop readiness checklist
- [codex-cli.md](codex-cli.md) - Codex access and basic usage notes
- [git-workflow.md](git-workflow.md) - branch, diff, review, and commit workflow
- [project-instructions.md](project-instructions.md) - how to write and maintain `AGENTS.md`

## Recommended Setup Order

1. Confirm local prerequisites in [checklist.md](checklist.md).
2. Review Codex usage in [codex-cli.md](codex-cli.md).
3. Add or customize project instructions with [project-instructions.md](project-instructions.md).
4. Practice the branch workflow in [git-workflow.md](git-workflow.md).
