# Codex Workshop Resources

This folder contains reusable prompts and templates for the Codex Workshop.

## Prompts

- [bug-investigation.md](prompts/bug-investigation.md) - structured debugging prompt
- [code-review.md](prompts/code-review.md) - high-signal review prompt
- [implementation-plan.md](prompts/implementation-plan.md) - plan-before-code prompt
- [project-overview.md](prompts/project-overview.md) - repository overview prompt

## Templates

- [AGENTS.basic.md](templates/AGENTS.basic.md) - starter project instructions
- [task-brief.md](templates/task-brief.md) - scoped task request template

## How to Use

Copy a prompt, replace bracketed placeholders, and paste it into Codex. Keep prompts specific to the task and include the desired verification standard.
