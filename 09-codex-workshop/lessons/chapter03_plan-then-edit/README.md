# Chapter 3: Plan Then Edit

## Goal

Practice asking Codex for an implementation plan before making changes.

## Exercise

Ask Codex:

```text
I want to add a small feature. First inspect the relevant files and give me a concise implementation plan. Do not edit yet.
```

After reviewing the plan, approve the work:

```text
Approved. Implement the plan and verify it.
```

## Outcome

Participants learn the plan, approve, edit, verify loop.
