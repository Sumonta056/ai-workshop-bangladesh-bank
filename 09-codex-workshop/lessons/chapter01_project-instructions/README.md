# Chapter 1: Project Instructions

## Goal

Learn how `AGENTS.md` guides Codex inside a repository.

## Exercise

1. Open the root `AGENTS.md`.
2. Identify the role, workflow, safety rules, and command placeholders.
3. Ask Codex:

```text
Review this AGENTS.md and tell me what is specific, what is generic, and what should be customized for this project.
```

## Outcome

Participants understand how project instructions shape Codex behavior before any code changes happen.
