# Chapter 2: Setup and Sandboxing

## Goal

Understand what Codex can read, write, and run in the current workspace.

## Exercise

Ask Codex:

```text
Inspect the repository structure and summarize the writable project areas, important config files, and likely setup commands.
```

## Discussion

- Why read-only inspection should come first
- When dependency installation needs approval
- Why destructive operations require explicit permission

## Outcome

Participants can explain how Codex works safely inside a shared working tree.
