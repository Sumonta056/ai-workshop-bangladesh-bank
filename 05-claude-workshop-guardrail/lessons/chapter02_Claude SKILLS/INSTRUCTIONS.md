## Coordinator's Instructions

1. Explain why Claude SKILLS are required and how they differ from custom agents.
2. Demonstrate the basic structure of a skill.
3. Discuss best practices for creating effective skills.
4. Show how to create a Claude skill with a simple example.
5. Demonstrate SKILLS applications outside of coding scope.

## Learning Outcomes

1. Understand the importance of creating Claude SKILLS for specific tasks and how they differ from custom agents.
2. Be able to create a simple Claude SKILL with a clear structure.
3. Learn best practices for designing reusable, effective skills across diverse projects.
4. Recognize the strength and versatility of SKILLS applications outside the coding domain.
